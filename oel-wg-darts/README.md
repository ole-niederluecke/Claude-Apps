# Öl WG Darts Trainer

Darts-Zähler und Trainings-App: X01, Cricket, Trainingsspiele, Turniere (K.-o., Doppel-K.-o., Liga) und Statistiken.

- **Öffnen:** `https://ole-niederluecke.github.io/Claude-Apps/oel-wg-darts/`
- Läuft im Browser und lässt sich über „Zum Home-Bildschirm“ als App mit eigenem Symbol installieren.
- Funktioniert offline. Die Daten liegen nur auf dem jeweiligen Gerät, Sicherungen gehen über Einstellungen → Backup.

## Dateien
| Datei | Inhalt |
|---|---|
| `index.html` | Die komplette App |
| `sw.js` | Offline-Cache |
| `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` | App-Symbol und Installation |
