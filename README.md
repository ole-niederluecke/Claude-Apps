# Claude Apps

## Öl WG Darts Trainer
Darts-Zähler und Trainings-App im Ordner [`oel-wg-darts/`](oel-wg-darts/): X01, Cricket, Trainingsspiele, Turniere (K.-o., Doppel-K.-o., Liga) und Statistiken.

Die App läuft im Browser und lässt sich über „Zum Home-Bildschirm“ als App mit eigenem Symbol installieren. Sie funktioniert offline. Die Daten liegen nur auf dem jeweiligen Gerät, Sicherungen gehen über Einstellungen → Backup.

## LT DSHS Köln (Leichtathletik-Trainingsgruppe)
App für die Leichtathletik-Trainingsgruppe im Ordner [`la-trainingsgruppe/`](la-trainingsgruppe/): Konten mit den Rollen Admin, Trainer und Athlet, Wochenplan-Import aus Excel mit Archiv, Übungssammlung mit Videos, Termine mit Zu- und Absagen (Absagegrund nur für Trainer), Einstellungen inklusive Backup sowie Hell- und Dunkelmodus. Die Daten liegen in einer gemeinsamen Supabase-Datenbank. Wie man sie einrichtet, steht in [`la-trainingsgruppe/EINRICHTUNG.md`](la-trainingsgruppe/EINRICHTUNG.md). Ohne Einrichtung gibt es einen Demo-Modus.
